# lpnu-lab-reports

[English](README.md) | Українська

Скіл для агента, який пише й оформлює лабораторні звіти кафедри систем штучного інтелекту Національного університету «Львівська політехніка».

- Звіти українською мовою.
- Оригінал — LaTeX. Скіл експортує з нього PDF та редагований файл Word (DOCX).
- Враховує правила ДСТУ 3008:2015 та обраний користувачем компактний профіль; явні вказівки користувача мають пріоритет.
- Не для бакалаврських, магістерських і курсових робіт.

## Встановлення

```sh
npx skills add Aler1x/lpnu-knssh-lab-reports
```

Потім попросіть агента, наприклад: «Використай lpnu-lab-reports, щоб зробити звіт до лабораторної 3 з мого коду та результатів».

## Вимоги

| Результат | Потрібно |
|-----------|----------|
| PDF | XeLaTeX (`latexmk -xelatex`) і шрифт Times New Roman |
| DOCX | [Pandoc](https://pandoc.org) і Python з `python-docx` |

## Вміст

| Шлях | Що це |
|------|-------|
| `SKILL.md` | Інструкції для агента |
| `references/format.md` | Правила оформлення (ДСТУ 3008:2015) |
| `references/export.md` | Експорт у PDF і DOCX та перевірки |
| `assets/report.tex` | Шаблон звіту з титульною сторінкою |
| `assets/university-logo.png` | Логотип університету для титульної сторінки |
| `scripts/export_docx.py` | Експорт з LaTeX у DOCX з форматуванням шаблону |

У компактному профілі відступи заголовків — 21 пт у Word та один `\baselineskip` у LaTeX. Експортер відновлює прості цитування й бібліографію. `scripts/check_pdf_layout.py` позначає порожні горизонтальні смуги понад 20% робочої висоти сторінки; PDF і Word потрібно окремо відрендерити й переглянути.
